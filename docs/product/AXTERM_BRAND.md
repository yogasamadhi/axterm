# AxTerm brand mark

Updated: 2026-09-21

The AxTerm mark is a continuous `AX` monogram. The rising left stroke forms the `A` for access,
while the crossing strokes form the `X` for connections across terminal, SSH, SFTP and remote
protocols. The open triangular counter echoes a terminal chevron without copying the common
terminal-window or `>_` icon.

## Assets

- `apps/desktop/build/icon.svg` is the editable source of truth.
- `apps/desktop/build/icon.png` is the 1024×1024 Linux and general-purpose raster.
- `apps/desktop/build/icon.icns` contains the macOS application icon set.
- `apps/desktop/build/icon.ico` contains the Windows 16–256 px icon set.

The application tile uses a midnight green surface so the mark stays distinct on both light and dark
desktops. The monogram transitions from mint `#8CF59E` to mint green `#56D8AA`; its large strokes and
generous safe area preserve the silhouette at 16–32 px.

## Usage

- Keep the complete rounded-square tile for application icons, installers and repository avatars.
- The monogram may be used without the tile only on a solid, high-contrast background.
- Keep clear space equal to at least one stroke width around the mark.
- Do not add terminal traffic-light dots, a window frame, extra glyphs, shadows or text inside the tile.
- Use the product name `AxTerm` next to the mark when a word label is needed.

The deterministic SVG geometry is the only editable source used to generate the
packaged icon variants. Its authorship and trademark clearance remain subject to
the separate product-mark review before release.
