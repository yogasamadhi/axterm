# Axterm independent commercial-release acceptance matrix

Updated: 2026-09-25  
Authority: [ADR-016](../adr/ADR-016-independent-open-source-product.md), [ADR-021](../adr/ADR-021-immediate-legacy-prototype-compatibility-removal.md), [MASTER_SPEC](../architecture/MASTER_SPEC.md)  
Work order: [COMMERCIALIZATION_CLEANUP_PLAN](COMMERCIALIZATION_CLEANUP_PLAN.md)  
Live result: [STATUS](STATUS.md)

This matrix replaces the Legacy Prototype 1:1 score as the future release checklist. `Open` means evidence is missing, not that the feature is absent. `In progress` means implementation has started but the full exit gate is unproven. `Accepted` requires the named artifacts and platform-scoped tests, not a self-reported percentage. The former 122-row matrix remains historical and its states are never automatically carried over.

**ADR-022 scope note (2026-09-26):** this IR matrix continues to track full
three-platform native acceptance. The current task's minimum commercial-release
completion is separately defined by [MCR-01～04](MINIMUM_COMMERCIAL_RELEASE.md):
common source/rights/services and a formal macOS arm64 artifact. Windows/Linux
remain compatibility targets, but the owner tests them on other native machines;
their IR rows stay In progress/Open until actual evidence arrives. Completing the
MCR checklist may close the current commercial-release task, **not** relabel
unverified Windows/Linux IR rows as Accepted.
