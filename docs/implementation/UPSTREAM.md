# Upstream reuse ledger

Updated: 2026-09-14

The user requested Electerm's desktop feature set and UI/UX as a 1:1 behavioral
reference. It is retained as the Git submodule `vendor/electerm` at revision
`799bedef98c1deae676ae03041719de98d3b57f1` (package version `5.5.0`); its MIT
license remains in the submodule. Axterm does not build or ship the Electerm
application.

ADR-003 fixes this revision as the acceptance baseline. Product behavior and
visual hierarchy are reimplemented with Axterm's stack. Updating the baseline
requires a new ADR, a parity-matrix diff and regenerated golden scenarios. See
[ELECTERM_PARITY_SPEC](../product/ELECTERM_PARITY_SPEC.md) and
[ELECTERM_PARITY_MATRIX](ELECTERM_PARITY_MATRIX.md). The work-package order is
maintained in [ELECTERM_PARITY_ROADMAP](ELECTERM_PARITY_ROADMAP.md).

The Phase 1–10 implementation reviewed the following upstream areas and adapted
their useful protocol/lifecycle patterns to Axterm's ports, Application Services,
REST contracts and bounded resource model. Axterm implementations are TypeScript
and were written for this architecture rather than copied as an upstream subsystem.
