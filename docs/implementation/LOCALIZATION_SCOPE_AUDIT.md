## Historical replacement record (2026-09-20–23)

The following counts and surface descriptions preserve that record's dated scope. Use the
executable catalogs and the current paragraph above for today's key counts and behavior.

### Replacement scope at that recorded stage

`bun run locales:scope` parses Renderer TypeScript/TSX calls to the `t()`
translator. It resolves literal keys and the five fixed dynamic call sites
from the activity rail, layout selector and settings category definitions.
Unknown dynamic expressions, aliased `useI18n().t` bindings and property-
access `.t()` calls require an explicit audit. The check runs in `bun run check`.

## Per-language draft and review ledger

All entries below have 45 non-empty keys and matching placeholder sets. The
draft date is 2026-09-20. “Pending” means no qualified human language and
rights reviewer has signed off; a passing generator is not that review.

The executable record is
`scripts/localization/axterm-navigation-review-ledger.json`. It records the
44-key Renderer-scope SHA-256, draft source language/method/date, whether the
draft author has been recorded, and independent language and rights-review
states for every locale. `bun run locales:check` verifies it with the catalog:
a changed key scope invalidates the ledger, and a `reviewed` state requires a
named reviewer/date for both review types plus a recorded draft author. All
current records intentionally remain `pending` with author attribution
`unrecorded`; this is evidence of the outstanding review work, not a claim that
an unknown person authored or approved a translation.

The 2026-09-23 rendered connection-configuration review also removes the
remaining English `Profile` noun from its Simplified Chinese title,
description, search, empty state, form/actions, Host selector,
saved-credential guidance and sync category. A unit guard covers those exact
catalog entries, and source plus packaged Electron journeys reject the former
mixed-language literals. This improves technical coverage but does not promote
the `zh-CN` catalog from pending human review.

The 2026-09-23 SSH-interaction review moves Unknown/Changed Host Key and
keyboard-interactive presentation out of Runtime-authored Simplified Chinese
copy. The Runtime now returns structured, language-neutral interaction data;
the Renderer supplies the visible title, explanation, field labels, warning,

## Evidence and remaining gate

- `bun run locales:check`, `locales:scope`, `locales:draft` and focused unit
  tests pass. The generator reads no `vendor/legacy-prototype` path; a new generated
  file is deterministic and `--check` rejects drift.
- The source Electron H-11 journey covers the four retained IDs, immediate
  switching and English cold-restart persistence. The copied macOS arm64
  `package:dir` H-11 journey also cycles the same four IDs, asserting
  `html.lang`, LTR direction and an exact catalog label each time. Both journeys
  open the current terminal search after selecting Japanese and Traditional
  Chinese, asserting the localized search placeholder and close control rather
  than only reading catalog values. Earlier Arabic RTL evidence is historical
  because Arabic is no longer a product locale. This is unsigned
  directory-package evidence, not an installed or Windows/Linux release result.

  with 11 conditional platform/fixture skips on macOS arm64. The rebuilt
  unsigned `package:dir` app passes the H-11 journey and two exact-text
  license/About checks. This is source and one-platform package evidence, not
  Windows/Linux or installed-release certification.
