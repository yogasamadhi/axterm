## 修改与最终行为

文件和 AI 视图通过静态 imports 由 App 组合，公共 Panel/Modal/空态/错误展示独立为
`app/ui/`。文件路径、历史与 drag payload 的纯模型位于 `app/files/file-manager-model.ts`；
目录授权归属由 `LocalDirectoryGrantOwner` 管理，Client 原生目录请求由
`useLocalDirectoryGrant` 负责。每次选择产生独立身份，最后发起的选择才能被接纳；
替换时撤销旧授权，卸载时撤销当前授权，过期结果返回后立即撤销。旧授权的异步
撤销先完成，也不能让已被替换的选择再次更新页面。没有积累待选目录或授权队列。

AI 附件拆为 `AttachmentDraftOwner` 与 `useAiAttachments`。附件准备、浏览器文件
stream、取消、移除和卸载均有明确所有者；同步 operation lock 防止同一轮重复提交。
取消会中止所属 AbortController，已接纳草稿仍保留；迟到原生 Grant 被释放，迟到
Runtime preview 被丢弃，卸载结果不再更新 UI。既有 8 附件 / 100 KiB 总量边界、
重复文件判断和 Runtime 脱敏预览保持。成功发送仅移除本次提交的 IDs，避免清空
在发送期间新准备的附件；原始附件正文仍由 Runtime 持有。

终端 AI 建议和选区解释的 Client workflow 移入 `useTerminalAiActions`；Shell 仅传入
模型、Client、查询缓存和打开工作区回调。AI run 的等待属于 `waitForAiResult`，
保留既有 20 秒轮询预算与 200ms 节奏，读取返回后再次检查终端 AbortSignal，避免
迟到成功成为已关闭终端的建议；timer/listener 在完成、超时和取消时清理。该预算
是轮询预算，不作为 HTTP transport 或真实模型端到端延迟承诺。

本轮命令面板沿用 OP-02 的 component/model/hook，传输中心沿用 OP-04 的静态
组件与行级 mutation hook。App 不重复目录授权、附件接纳或 AI polling 状态机。
Modal 清理尚未执行的 autofocus frame，恢复焦点时再检查目标仍连接。现有会话文件
视图保留规则与 Inspector 入口不变，没有以删除功能或机械分割行数作为验收。

Renderer 仍只调用 Client/Contract；没有引入 Runtime implementation、原生 vendor、
Plugin Kernel、Extension Host、动态注册或业务 IPC。OP-06 没有新增 HTTP operation；
OP-07 新上下文 route 将从开始使用独立模块与 Application Service。没有依赖变更。
