## 修改与执行边界

- 命令面板移入 Renderer 静态 `app/command-palette/`：组件负责搜索和键盘，纯模型
  负责分组、别名、限量与可用性，hook 只保存本次应用会话的使用元数据。没有动态
  插件、全局 service locator 或 Renderer 原生访问。
- 可执行动作复用 `SHORTCUT_ACTIONS` 的 ID、四语言名称和有效快捷键绑定，经
  同一个 `runShortcutAction` 执行。固定鼠标中键手势仍在快捷键设置中，不伪装成
  可执行命令。分组包括常用/最近、操作、终端、功能页、会话、主机与保存的工作区。
- 上下键、Home/End 选择，Enter 执行选中项，Esc 或关闭按钮返回入口焦点；Tab
  保持在弹窗内，IME 组合阶段不执行或关闭。重复键和已接受的分发有同步保护。
  弹窗打开期间不分发后台快捷键；既有安全确认弹窗优先。
- Host 结果调用现有 SSH 连接路径；连接前通过 Client 读取当前连接，避免复用已经
  关闭的缓存连接。会话结果激活现有会话，保存的工作区调用既有加载/资源回收路径；
  文件区和传输中心使用已有入口，不添加占位操作。
- 可用性由共享纯函数表达；打开面板时只采样当前终端的可用/选中/路径布尔状态，
  渲染不读取 xterm ref，执行时重新检查当前上下文。SSH 未连接、没有会话或没有
  选择时显示原因。断线后的本地缓冲区搜索/复制保留，发送输入要求有效连接。
- NFKC/大小写/空白归一化并匹配四语言别名；展示最多 50 项，继续输入可找到未
  展示的结果。使用记录最多 50 项，仅含动作 ID、有限次数和排序序号；不含标签、
  地址、secret 或终端内容，不写 localStorage/业务 DB，也不开启终端历史持久化。
- 连接等待移入 `app/connections/wait-for-connection.ts`，通过显式 Client 列表与
  生命周期上下文协作；默认等待上限仍为 120s。请求返回时再次核对所属页面与
  generation，拒绝迟到的旧响应。暂停计时器与 abort listener 有确定性释放，
  Shell dispose 取消所属等待。翻译、启动与 deep-link 回调 ref 在
  layout effect 更新，设置入口 nonce 使用状态递增，不依赖墙钟时间。
- 新增十八项四语言文案，当前核心目录每语言 2,565 项；来源和人工语言审校继续
  pending。历史 OP-04 的 2,547 项记录保留日期，当前交接范围与测试同步更新。

## 失败定位与证据限制

早期桌面断言误用了不存在的 `.file-manager`、未先聚焦语言入口、以及与终端重连
展示不同的 tab disconnected class。已按实际语义区域、入口焦点、重连提示及真实
SSH connection count 校正；没有降低键盘执行、焦点恢复或协议验收范围。
另一轮错误使用 DOM inline script 触发 CSP 阻止，改用项目已有测试 init script；
Host Key 的确认按钮实际采用表单默认 submit，改为核对明确的可访问名称。

活动会话 ID 与 connected 状态，再核对新连接实际输入和持久指纹，未删除字节证明。
