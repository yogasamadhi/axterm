## 修改与最终行为

常规页以实际偏好为入口：语言设置置顶，隐私设置使用已有地址遮蔽能力；窗口、标签、
活动栏和行为组织为“外观与工作区”，代理与 Known Host Keys 组织为“连接与主机信任”。
终端、快捷键、连接配置与法律信息沿用现有分类和入口，没有引入不可用设置。
运行资源计数移到默认收起、有明确标题的高级诊断；其 raw key 只在排障区展示。
更新状态与实际 check/download/cancel/install 保留既有 Host/REST 路径与能力限制。

新增静态 `app/settings/` 组件：诊断组件拥有查询/导出/错误状态，隐私组件拥有保存与
恢复状态。诊断只在展开时加载与轮询，收起或卸载时移除 query observer，消费
TanStack Query 的 AbortSignal 取消所属 Client 请求。调用方取消不重置 generation
鉴权；真实 loopback Client 回归确认后续查询仍使用同一次 bootstrap。
导出沿用原生 save-file Grant 与 Runtime 接口，有同步重复提交保护、成功/失败说明，
finally 撤销所属 Grant；迟到的文件选择与完成结果不更新卸载组件。没有新的业务 IPC、
Renderer 原生导入或 Provider 访问。

隐私保存复用 `updateCachedSettings`：取消迟到读取、采用最新缓存版本、失败时更新
可重试版本，不自动重放拒绝的 mutation。错误显示明确本地化说明，保存值不被失败
勾选覆盖，也不将 Runtime detail/secret canary 展示给用户。首轮证明原始 checkbox
尺寸不等于点击标签范围；已为隐私点击标签设置 28px 最小高度，键盘仍聚焦 input。

本轮 CSS 仅整理涉及的分组与诊断职责；900px 以下设置列缩为有限侧栏与 flexible
content，长分类文字可换行，侧栏可滚动，表单和 header 在 200% 下重排。正常三视口
的既有自有主题、快照阈值与 Architecture Gate 保留。没有重做全部主题。
