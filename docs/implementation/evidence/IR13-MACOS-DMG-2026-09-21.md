## Installed-app procedure and result

1. `bun run package` produced the DMG, ZIP and blockmaps. The regular
   production build/layout check passed before electron-builder emitted the
   installer files.
2. `sh scripts/test-macos-dmg.sh release/Axterm-0.10.0-arm64.dmg` verified the
   DMG CRCs with `hdiutil verify`, attached it read-only at a newly created
   temporary mount path, copied `Axterm.app` with `ditto` into a separate
   temporary installation directory, detached the image, and only then launched
   the copied application.
3. The copied-outside-checkout installed application passed 15 applicable
   packaged Playwright journeys: packaged notices/About, rebuilt Electron-ABI
   native modules, only the four product-selected Electron runtime locale
   families, independent FTP Widget (including a separate system `curl`
   client's forced-PASV list/binary-upload/binary-download path and an active
   `--ftp-port -` byte-exact `STOR`/`RETR` path), XMODEM/ZMODEM/TRZSZ local-PTY
   binary round trips, IronRDP initialization, migration warnings,
   signed-updater fixture behavior, source/Node independence, Shell/workspace,
   language switching and prior-schema/local-Vault migration. Nine Windows/Linux
   or optional-SSH-fixture journeys were conditionally skipped.
4. A post-test mount inspection found no remaining temporary
   `axterm-dmg-mount.*` path. A pre-existing volume named
   `/Volumes/Axterm 0.10.0-arm64` was left untouched: `hdiutil info` identifies
   it as a system iOS Simulator Runtime image, not this release DMG.
5. The concrete Resources directory was passed to `bun run sbom:packaged` and
   the release directory to `bun run release:hashes`, producing the sidecar and
   top-level hash manifest named above.

The packaged test also verified the refreshed mint-only `icon.icns` against the
source product-asset inventory. Its Electron framework includes only the four
selected runtime locale families: 20 compatible macOS `.lproj` variants total
3,160 KiB. Those compatible region/gender variants do not create selectable
product languages.
