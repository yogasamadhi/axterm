## Scope and environment

This record covers a fresh Axterm `0.10.0` arm64 DMG built from that
working-tree state on macOS arm64. The package was written to an isolated temporary
directory; the repository `release/` directory was not used or modified. The
packaging wrapper set `CSC_IDENTITY_AUTO_DISCOVERY=false`, and electron-builder
reported that application code signing was skipped. This is not a signed,
notarized or publicly distributed release.

## Installed-app procedure and result

1. `bun run build` passed, including the separate Runtime build and production
   package-layout check.
2. `node scripts/package-desktop.mjs --output <new empty absolute directory>`
   produced the unsigned arm64 DMG and ZIP without writing into `release/`.
   `hdiutil verify` accepted the DMG CRCs; `unzip -tq` found no ZIP errors.
3. `sh scripts/test-macos-dmg.sh <DMG>` attached the image through
   `diskutil image attach --nobrowse --readOnly --mountPoint`, copied
   `Axterm.app` with `ditto` into a separate temporary installation directory,
   detached the image before launch, and verified the installed Resources
   against the SPDX sidecar. The current attach command avoids the deprecation
   warning from the older `hdiutil attach` interface.
4. The copied-outside-checkout application passed **21 packaged Playwright
   journeys**; **10 Windows/Linux, historical-public-installer or optional SSH
   fixture journeys** were conditionally skipped. Passing journeys included
   packaged notices/About, native-module ABI, the four selected Electron
   locale families, FTP Widget, XMODEM/ZMODEM/TRZSZ local-PTY transfers,
   migration/configuration accessibility, Legacy Prototype custom-theme migration,
   legacy-data and independent Axterm-format recovery, Gist/named-file sync
   migration, updater isolation, Host Key review, Shell/workspace behavior,
   locale restart/upgrade and prior-schema/Vault migration.
5. The test script removed its temporary mount and install directories on exit.

This confirms that candidate's macOS arm64 DMG install-path and packaged regression
coverage. It does not prove a signed/notarized distribution, authenticated
production updater feed, upgrade from a preserved publicly distributed old
installer, a live cloud account, Windows/Linux installation, human
source/rights or design review, public migration-window acceptance, or
new-repository creation. IR-13 remains **Open**; IR-02, IR-08, IR-10, IR-11 and
IR-14 remain subject to their separate gates.
