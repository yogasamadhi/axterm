## Checks performed

The packaged Electron renderer received test-only `axe-core@4.13.0` through
Playwright's context init script; production CSP and renderer code were not
changed for injection. One packaged journey passed (**1/1**) and audited six
actual rendered states against WCAG 2.0 A/AA, 2.1 A/AA, 2.2 AA and axe
best-practice rules:

1. Startup Shell.
2. Legacy-data import preview selected through the native File Grant flow.
3. Completed legacy-data migration.
4. Malformed legacy-data import error.
5. Independent Axterm configuration import preview, including the local Vault
   preservation note.
6. Host Manager after migration, with imported Bookmark cards present.

The packaged flow focuses the migration, import, retry, configuration
export/import, preview-dismissal, Settings-close and Host Manager controls and
activates them with Enter before checking the resulting state. This is
automated keyboard-activation coverage; it is not a complete Tab-order or
manual assistive-technology review.

The Host Manager scan exercises the populated view whose 9 px connection-state
copy previously measured 3.95:1 contrast. It passes after the style switched to
the Axterm semantic muted-text token.

Reproduce by building into a fresh temporary directory and running:

```sh
AXTERM_PACKAGED_APP=<temp-dir>/mac-arm64/Axterm.app \
  bunx playwright test --project=packaged \
  --grep 'packaged migration and configuration surfaces pass rendered accessibility scans'
```

## Limits

This is a local unsigned directory package, not a signed/notarized DMG or an
installed public release. It covers only macOS arm64 and synthetic fixtures;
it does not provide Windows/native-Linux, full manual keyboard or assistive
technology review, translation/brand approval, historical real-user export, or
design sign-off. It strengthens IR-10 engineering evidence without accepting
IR-08, IR-10, IR-13 or the overall release.
