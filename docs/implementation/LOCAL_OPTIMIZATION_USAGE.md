## 命令、会话与文件入口

右侧图标栏最上方为 AI 助手，后面是添加书签、连接/书签与设置（后面三项可按设置调整顺序）。
AI、主机和其他功能共用其左侧的弹出侧栏，设置之外不创建独立功能标签或占用主区域。
共用侧栏在宽窗口为 520px，窗口宽度不超过 1100px 时为 440px；窄窗口覆盖展开，
并按可用视口限制宽度。
AI 模型选择独占一行，选中名称完整显示，较长名称自动换行；模式选择位于下一行。
右侧图标悬停或获得键盘焦点时，在左侧显示当前语言的名称提示，移开或按 Esc 收起。
书签侧栏的“管理”在同一侧栏中展开管理工具；添加 SSH 主机只打开创建弹窗，保留当前
侧栏的展开状态和内容，不自动打开主机书签。保存、连续添加或取消也保持当前界面；
保存并连接失败时显示错误弹窗。编辑同样使用弹窗，当前终端保持显示。
侧栏标题只显示当前面板名称。活动栏已移除“＋”快速开始入口，终端标签栏保留新建本地终端
按钮及会话菜单，菜单仍可快速连接或添加书签。

普通冷启动显示单窗格中的一个已连接的新本地终端，忽略上次无存活会话的主机/设置页、
旧终端与分栏。已保存的命名工作区可手动加载；显式配置的启动书签、命名工作区和连接
启动目标按配置打开。Renderer 刷新复用同一 Runtime generation 的存活会话。

同步设置、组件和隧道集中在设置内部；此前的闪电（快速连接）、图片/山景
（终端配色）、文件夹（文件传输）和 ⌘（快捷命令）保持移除。快速连接使用
“＋”菜单；终端配色从设置顶部“应用外观”进入，已保存命令从设置顶部
“已保存命令”进入，也可使用终端底部的快捷命令面板。文件管理使用当前会话的
“文件管理”页签，传输中心仍可通过命令面板打开。

旧侧栏配置保留可读，按已有顺序显示添加已保存连接、书签和设置；缺失的两个
固定入口会在显示层补回，若旧配置只选了已移除项，则显示三个默认选项。
设置入口可按需隐藏；收进内部的工具不会重新显示。

从 Finder 拖入本地文件夹到终端，直接填入原始目录的完整路径，不复制目录，
不自动按 Enter；中文、空格、引号和 Shell 特殊字符经过引用。拖到文件管理的
本地面板，直接加载该文件夹并在地址栏显示完整路径；这里只接收一次一个目录。
更换目录和关闭会话会释放授权。拖入远端面板的目录仍使用“上传目录”操作。
普通文件的现有询问、临时路径和上传流程保留。目录拖放边界见
[ADR-026](../adr/ADR-026-native-directory-drop-metadata.md)。

macOS 顶栏为红黄绿系统按钮保留独立区域，工作区标题和收起侧栏后的首个
页签自动避让；展开侧栏后标签紧靠工作区左边。界面缩放时保留区同步换算，
缩小到 50% 也不会让标题、标签或设置导航压到系统按钮上。

终端使用拼音等组合输入时，退格/删除只修改尚未确认的输入，Enter/Shift+Enter
只用于确认输入，方向键和 Esc 由输入法处理。已确认的文字保持在终端中；本次
确认的文字交由 xterm 提交一次。结束或取消组合输入后，退格恢复设置中的
`^?` / `^H` 行为，Enter 和 Shift+Enter 恢复普通终端输入。此行为自动生效，
无需增加输入法设置。

按 Cmd+K（macOS）或 Ctrl+K 打开命令面板，输入命令、功能、Host 或已保存工作区
名称。上下键选取、Enter 执行、Esc 返回；面板显示当前可用性和最多 50 个结果。
Host 结果进入真实连接流程，首次或变更 SSH Host Key 仍须确认。最近/常用排序
只记录当前会话的动作 ID 与使用次数，不保存输入的命令、终端输出或服务器 secret。

文件操作属于所选本地终端或 SSH 连接。使用文件区的当前目录授权选择上传/下载
目标，检查确认中的远端/本地路径，随后在传输中心查看真实进度、完成或错误。
失败/取消不必然可重试：Runtime 只在当前 generation 保留有限请求；连接失效或
重启后按界面重新连接、选择文件并授权。不能从旧记录自动恢复 Grant 或覆盖授权。
服务器不能安全原子覆盖时会保留原文件并提示失败；这不是传输成功。

目录选择只接受最后发起的一次结果；替换、所属会话关闭和卸载都会释放授权。
原生对话框迟到返回的 Grant 也会撤销。操作目标跟随 active terminal，而不是最后
创建的标签。Terminal stdin/stdout 使用 Binary WS，消费完成才释放窗口；达到安全
上限时按提示恢复会话。测量预算与实际 Mac 证据见 [PERFORMANCE_BUDGETS](PERFORMANCE_BUDGETS.md)，
Mac 结果不能代表 Windows/Linux 原生表现。

## 设置与恢复

常规设置以语言和隐私为入口，外观/工作区与连接/主机信任按用途分组。高级诊断
默认收起；展开才读取 Runtime 资源信息，收起或离开时取消所属查询。导出先取得
本地文件授权，操作结束撤销授权。失败提示保持本地化，不显示 Runtime 原始 detail。

设置保存使用最新版本；保存失败时保持已保存状态，并提供重试或重新读取。
四个可选语言是简体中文、繁体中文、英文和日文，均支持 200% 布局回归。
当前核心目录每语言 2,612 项；完整草稿和工程测试不代表人工译文/权利审校完成，
见 [LOCALIZATION_FALLBACK_POLICY](LOCALIZATION_FALLBACK_POLICY.md)。

## AI 检查、生成、插入与执行

从 AI 助手侧栏的配置弹窗管理 Provider，再在侧栏输入问题或附加文本文件。“发送消息”先打开
实际请求检查，显示 Runtime 采用的问题、系统指令、上下文来源、包含/原始大小、
脱敏和截断状态；“确认并发送”才发起模型请求。可以返回修改问题、移除附件或
取消勾选最近对话历史。终端“使用 AI 解释”先打开已脱敏选区的待发送内容。
终端 ID 标识目标，不会因此自动收集全部历史、环境变量或其他文件。

历史最多选取最近 32 条；历史/显式上下文最多 24,576 字符，组装总量最多 131,072
字符。每个附件读取最多 50 KiB，8 个附件合计最多 100 KiB。来源大小是实际保留
文本的 UTF-8 字节，不是 token 估算。准备附件使用 File Grant；已知 AI Provider/
proxy 值只通过 application-local Host Vault 脱敏，凭据不进入业务数据库正文。

检查有效期五分钟，正文、来源、目标、配置或 Runtime 重启发生变化后需要重新
检查。切换、新建或删除当前对话会清理旧附件，取消和离开页面不接纳迟到预览。
确认发送后离开，迟到创建的 run 返回 ID 后也会被取消。失败时重新检查，不复用旧
receipt，也不自动重试模型请求。

生成命令只产生内容；复制或插入终端仍需用户审核，插入不会自动按 Enter。
Tool 执行审批独立于上下文检查：卡片展示 tool、risk、目标、参数、摘要、有效期、
状态与结果。“运行一次”才允许已批准的修改操作；拒绝、取消、重复、参数/目标/
风险/摘要/有效期变化或 Runtime 恢复都不能复用旧批准。现有 Inspector 保留。
边界与验证见 [ADR-025](../adr/ADR-025-ai-context-review-receipt.md) 和
[OP-07 证据](evidence/local-optimization/OP-07-2026-10-03.md)。

本轮测试使用自动生成的 SSH/SFTP 凭据和 loopback HTTP Model Provider，不要求所有者
提供 Token。夹具只验证工程、协议和审批行为，真实云端连通性及模型质量仍属外部
验证。产品实际接入真实服务时仍需该服务自己的配置，这不影响本计划本地任务执行。
