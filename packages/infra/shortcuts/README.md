# @axterm/infra-shortcuts

Axterm-owned adaptation of the locked DSH physical-key command service. Public
contracts are in @axterm/plugin-api/shortcuts and @axterm/ui/shortcuts. Features
register and withdraw their own commands. Configuration supplies accepted
preferences through generated Remote/model and ctx.storage; the browser stores
only a derived window-local catalog and recording draft. No localStorage or
shell preference file is used. Desktop routes native keys through the validated
per-window shell bridge; Web/Linux use the DSH DOM arbitration rules.

SOURCE.json and the MIT notice record upstream scope. Axterm lifecycle, storage
seat, current feature defaults and native protocol additions retain the separate
LICENSE.AXTERM notice. This package does not mount a React root or run business
services in the shell.
